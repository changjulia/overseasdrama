# 独立功能验收执行单

状态：数据盘点与冻结准备中；尚未产生功能验收通过结论。

## 数据冻结顺序

1. 确认 1 部连续前 10 集的真实片源、验收权限、集号映射与 SHA-256。
2. 按 8 个题材和来源子类交叉抽取约 40 条真实跑量素材，并记录跑量证据等级。
3. 人工在看不到系统输出的环境中填写黄金标签。
4. 对黄金文件和 manifest 计算 SHA-256，冻结版本；此后修订必须新建版本。
5. 再运行系统输出，分别计算总体、逐题材、人物资产复用困难子集和跨题材正/负例指标。

## 题材层

- 豪门/隐藏身份
- 婚恋背叛
- 复仇逆袭
- 家庭伦理/亲子
- 狼人/吸血鬼/奇幻
- 穿越/重生
- 职场/契约婚姻
- 犯罪/悬疑/救援

目标每类 4～6 条；真实分布不足时不得伪造或强行改标，报告真实占比并补样至每类至少 3 条。

## 必填黄金字段

素材来源子类、T1/T2、钩子事件、人物关系、冲突、情绪、悬念、叙事承诺、留人评分、对应正片事件、高光起止、安全边界、是否可拼接、跑量证据等级。来源类型用于评测，不作为匹配准入条件。

## 报告切片

总体和每个题材分别输出：题材识别、外搭判定、T1/T2、分析完整率、Top3 匹配命中、故事完整度、留人评分、承诺兑现、连通性、样本数。另列人物资产复用困难子集、跨题材负例、合理跨题材结构迁移正例。

## 失败台账

每个失败记录：样本和版本、预期、实际、时间码、根因、修复提交/变更标识、复测命令、复测证据。开发实现和独立验收结论分开记录。
