# 三样片 Golden 盲性审计 v1

审计结论：三份 v1 从未读取当前被测系统输出，但冻结前监督者读取了 `artifacts/golden-hook-samples/samples.json`。该文件不仅含媒体包装信息，还包含 `candidateSubtype`、`candidateConfidence` 等旧的内容判断。因此不能继续标为严格 `frozen_blind`，统一降级为 `frozen_with_prior`。

影响范围：

- 对事实事件、人物关系、冲突和时间码的判断主要来自原视频与带时码帧，污染风险较低但非零。
- 对“来源子类”字段存在直接先验污染；QS-GH-001/003 虽最终仍标待复核，也不能作为严格盲评证明。
- QS-GH-002 的人物资产复用型标签同时来自用户明确业务先验；这个先验应继续作为必须保留的业务真值，但后续评测者不能查看旧系统/视觉初判。

重新盲标方案：

1. 新评测者使用全新任务上下文，只接收三条原始视频路径、不可变媒体 SHA、字段 schema，以及用户明确的业务标签（3 条均为外搭正例；QS-GH-002 为人物资产复用困难正例）。
2. 禁止其访问 `artifacts/golden-hook-samples/`、当前三份 v1、任何系统输出、提示词或旧分析文档。
3. 先为每条视频独立产出事件、人物、关系、冲突、情绪、悬念、承诺、候选边界、时间码、理由、置信度、拒绝/降级条件；来源子类若没有原剧和血缘证据必须保持待复核（QS-GH-002 只登记用户业务真值及证据待补）。
4. 主监督者只做 schema/越界/媒体 SHA 机械校验，不给内容提示；冻结为 `golden-v2.json` 并生成 sidecar。
5. v2 冻结后再与 v1 做评测者间差异分析；不得为了贴合 v1 回写 v2。只有 v2 可进入严格盲评指标分母，v1 永久保留作审计轨迹。
