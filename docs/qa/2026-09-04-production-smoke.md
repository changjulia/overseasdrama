# Lumina 线上真实点击冒烟测试与缺口清单

测试日期：2026-09-04（北京时间）
站点：https://lumina.43-134-182-192.sslip.io/
方式：在 Edge 已登录的普通成员会话中实际点击；随后在独立内置浏览器中输入现有成员账号、点击登录复查。浏览器控制台与本地源码仅用于辅助定位，不代替点击验收。

## 结论

本轮冒烟不通过。成员登录成功、基础导航和空文件导入校验可用，但业务数据读取出现 HTTP 502，阻断“剧库 → 选择高光 → 多方案生成脚本”的主流程。不能将页面可打开等同于业务功能通过。

## 缺口清单

### G01 / P1：业务数据读取出现 502，核心创作流程无法进入

复现：登录 → 剧库；另一路：内容工厂 → 外搭钩子＋本剧正片 → 从右侧剧库选择。

实际：剧库长时间显示“正在读取剧库”，独立浏览器复查后最终显示“数据加载失败”；片源抽屉显示“正在读取素材…”。因此无法选择高光、进入多方案生成或播放片源。

浏览器证据：2026-09-04 07:50:09 UTC 捕获到 `PocketBase drama migration failed / HTTP 502`，同时 `hook_match_jobs`、`entry_precision_jobs` 读取失败。这里只能确定接口失败，尚未证明是数据库内存、代理或网络中的哪一项根因。

验收要求：普通成员打开剧库并选择真实剧目、高光；必要接口均成功，失败时有明确超时、重试和保留已有数据的反馈。

### G02 / P1：同步失败被表现成“没有数据”与“已同步”

复现：登录 → 我的创作 → 我的草稿；登录 → 任务中心。

实际：创作页显示“自动保存已开启、0 个草稿已同步”；任务页显示“暂无真实任务”。同时控制台记录 `Factory history sync failed / 钩子资产请求失败（HTTP 502）`、`PocketBase task sync failed`。

辅助定位：`app/page.tsx` 的任务与历史同步 catch 分支只记录控制台错误，没有把失败状态显示给用户。

影响：用户会以为历史记录丢失或任务不存在，可能重复生成。当前不能断言数据已丢失。

验收要求：区分加载中、成功为空、同步失败和缓存数据；失败时显示重试入口，不能宣称“已同步”。

### G03 / P1：线上展示固定运营数字，容易误导判断

复现：打开任意工作台页面和任务中心。

实际：侧栏一直显示“数据同步正常 / 最后更新 2 分钟前”；灵感大屏侧栏 128 与页面 0 不一致；任务页在暂无任务时仍显示“今日模型成本 $68.42 / 预算使用 54%”，排队 0 仍提示“预计 18 分钟”。

辅助定位：`app/page.tsx` 的 128 与同步文案、`app/features/operations/OperationsWorkspace.tsx` 的成本、预算与预计等待时间均为固定值。

验收要求：接入真实统计；尚未接入时显示“暂不可用”，不能把固定展示值作为运营状态。

### G04 / P2：内容工厂默认空状态缺少直接选剧入口

复现：未带入剧目时，直接点击侧栏“内容工厂”。

实际：默认拼接模式只有“请从剧库目标剧目进入内容工厂”的说明，没有可点击的选剧按钮；切换到外搭模式后才有片源抽屉入口。

验收要求：三种模式统一提供选剧入口，选剧后能继续当前制作模式。

### G05 / P2：窄窗口侧栏按钮缺少可读名称

复现：在内置浏览器的较窄视口中打开工作台。

实际：侧栏折叠为图标后，可访问性树中的按钮名称只有“✦ / ▣ / ⇄ / ♡ / ◈ / ◫”。账号菜单则有正确名称“个人账号菜单”。

影响：屏幕阅读器无法说明导航用途，用户也需要凭图标猜测。

验收要求：折叠导航保留完整 aria-label，并提供鼠标悬停提示；不依赖图标区分页面。
