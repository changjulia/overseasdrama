# 外搭钩子 + 正片剧集上线验收清单

> 状态：执行中
> 建立日期：2026-08-30
> 适用范围：外搭钩子、正片剧集及其共同的 Web、PocketBase、worker、媒体处理与运行保障
> 安全边界：本清单用于开发验收与上线准备，不授权生产部署、生产迁移或生产数据变更。

## 1. 使用规则

- 只有“证据位置”中的文件、记录或命令输出可以复核通过时才勾选；代码存在、计划已写或口头确认不算通过。
- `P0` 未通过即阻断发布；`P1` 原则上阻断发布，只有产品、技术与运维负责人共同记录风险接受和到期整改日期后才能放行；`P2` 可带明确后续计划上线。
- “负责人”表示交付角色，不代表当前已指派具体人员。上线前须把角色替换或补充为真实姓名/团队。
- 每次验收都应在“验收证据索引”登记执行日期、环境、提交 SHA、执行人和产物路径，避免只保留易失的终端输出。
- 合成 E2E 证明媒体管线能工作；真实业务验收还必须证明真实数据权限、业务连续性、人工观感和目标环境运行条件。两者不可互相替代。

### 4.2 合成隔离组件测试的适用边界

- 合成隔离组件测试可以确认：媒体格式处理、时间线执行、下载、FFmpeg 裁剪/拼接、自动质检、哈希和原子发布。
- 合成隔离组件测试不能确认：真实导入、分析、剧库/灵感/工厂 UI 跳转、真实匹配、内容质量、历史复播、剧集授权、付费告知、真实片源边界、生产网络与存储、业务人员审核体验。
- 夹具直接写数据库或预置 approved/verified/match 记录的测试永远不能作为最终业务链验收证据。
- 因此，即使本节全部通过，第 5、6、8、9 节仍必须独立通过。
