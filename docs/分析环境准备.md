# 分析 Worker 的 Python 环境

分析 Worker 依赖 `faster-whisper`、PaddleOCR 与 PaddlePaddle。为避免与系统 Python 或 Web/渲染 Worker 冲突，使用项目本地、已被 Git 忽略的 `.runtime/analysis-venv`。

当前支持 Python 3.9–3.12。不要使用 Python 3.13/3.14 创建该环境，因为重型 ASR/OCR 依赖未必提供兼容 wheel。

```bash
# 只检查；不会创建环境或下载依赖
bash scripts/setup-analysis-env.sh --check

# 预览将执行的命令；不会创建环境或下载依赖
bash scripts/setup-analysis-env.sh --dry-run --python /path/to/python3.12

# 明确确认后才进行重型安装
bash scripts/setup-analysis-env.sh --install --python /path/to/python3.12
```

安装成功后，让现有启动器使用该解释器：

```bash
LUMINA_PYTHON_EXE="$PWD/.runtime/analysis-venv/bin/python" \
  bash scripts/start-analysis-worker.sh --queue both
```

若安装失败，保留完整 pip 输出。优先检查 Python 版本、CPU 架构、网络和磁盘空间。在 Apple Silicon macOS 上如果 PaddlePaddle 没有匹配的 wheel，应将分析 Worker 放到受支持的 Linux x86_64 环境；不要强行修改系统 Python。模型密钥仍只放在 `.env.analysis.local` 或进程环境中，本脚本不会读取、生成或改写密钥。
