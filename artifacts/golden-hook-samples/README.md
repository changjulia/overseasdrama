# 黄金外搭钩子样本冻结记录

三条用户指定样本已按本机原文件冻结 SHA-256 与 FFprobe 媒体指纹，没有复制视频文件。

当前只能确认：三条均为人工指定的“外搭钩子成片”正例；第二条是“人物和视觉连续，但镜头为新制作”的困难正例。由于每条文件均为约 16.7～20.4 分钟的完整成片，钩子起止边界仍须逐条人工确认，不能把整条文件直接当成 5～60 秒钩子。

最终外搭归因必须完成与对应原剧完整片源的镜头级比对，结合制作血缘判断。人物是否来自原剧、风格是否相似以及 T1/T2 都只能作为辅助标签，不能单独决定外搭与否。

后续必须补齐：题材、T1/T2、钩子事件、人物关系、冲突、情绪、悬念、叙事承诺、留人评分、对应正片事件、高光起止、安全边界、是否可拼接、原剧 ID、镜头匹配报告和人工审核人。
